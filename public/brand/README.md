# Vayucred identity assets

## Approved system

- **Mark:** the three-field connected-system symbol in Pine Deep, Moss and Sky.
- **Wordmark base:** Fraunces SemiBold (600), optically spaced in the website lockup.
- **Display typography:** Fraunces 500–600.
- **Body, interface, data and labels:** DM Sans 400–700.
- **Background:** the SVG mark is transparent. Place it on Cream, Mist or White whenever possible.

## Files

- `vayucred-mark.svg`: canonical transparent web mark using brand-token colours.
- `vayucred-logo-source.png`: founder-approved source artwork retained for provenance.
- `../icon.svg`: browser and web-app icon derived from the approved mark.

Do not redraw the mark, substitute its colours, add shadows, or place it inside an unrelated badge. The source PNG may contain presentation effects; production interfaces should use the clean SVG.
